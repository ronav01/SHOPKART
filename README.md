# My Java E-Commerce Store 🛒

Hey! 👋 Welcome to my e-commerce console application. 

I built this project to simulate how online shopping platforms like Flipkart or Amazon work behind the scenes. It's a fully menu-driven app that runs in the terminal, letting users browse products, add them to a cart, and check out. 

## What it does
- **Browse the Store:** Check out the list of available products and their current prices.
- **Manage Shopping Cart:** Add items to your cart, see what you've already picked, and keep track of the total cost.
- **Checkout:** Finalize your order and generate a clear final bill.
- **Simple Navigation:** Easy-to-use numbered menus to move around the app.

## How I built it
I coded this entirely in **Java** to practice and apply core Object-Oriented Programming (OOP) concepts. Under the hood, it uses:
- **OOP Principles:** Encapsulation, Abstraction, and Inheritance to keep the code clean, organized, and modular.
- **Data Handling:** Arrays and Collections to store the product inventory and manage the user's active cart.
